#### Recap
The web service on port 80 ran WordPress. Weak credentials and the ability to edit server-side PHP led to a shell running as `www-data`.

Shell history exposed database credentials, and the database contained a weak MD5 password hash for a local account. That account had unrestricted sudo access, which led to root privileges.
