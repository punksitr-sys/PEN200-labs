#### Recap
Several HTTP ports returned the same landing page. Enumerating them individually revealed differences in the available paths.
The service on port 8088 served static pages and did not expose an authentication interface.
The account file exposed on port 7125 identified a single ordinary user, making that account the strongest SSH credential lead.

An exposed account file identified Geisha, whose weak SSH password yielded initial access. The SUID bit on base32 allowed privileged reads and exposed both the root flag and the root account's SSH key.
