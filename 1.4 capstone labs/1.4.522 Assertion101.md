#### Recap
HTTP and SSH were exposed. The PHP application evaluated untrusted content through an assertion-related code path, leading to execution as www-data.

The SUID aria2c binary exposed privileged writes to attacker-selected paths. That access undermined the root account's SSH authorization and led to root access.

Key concept: evaluating untrusted input through legacy PHP assertions can lead to code injection.
Key concept: a general-purpose file downloader should not run with SUID root privileges.
