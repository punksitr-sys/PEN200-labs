#### Recap
The scan identified SSH and HTTP. Directory discovery revealed Joomla and its administrator login. Site content provided plausible usernames and password candidates.
```txt
admin
joomla
administrator
joker
```
I used a Joomla-specific authentication check to review password strength.
```bash
nmap -sV --script http-joomla-brute --script-args 'userdb=users.txt, passdb=cewl.list, http-joomla-brute.hostname=192.168.196.79, http-joomla-brute.uri=/joomla/administrator/index.php,http-joomla-brute.threads=3' 192.168.196.79
# joomla:Gotham - Valid credentials 
# joker: guys - Valid credentials 
# administrator: spread - Valid credentials 
# admin: guys - Valid credentials
```
Only the first reported credential was valid. The session cookie issued after success caused later results to be false positives.
Weak Joomla administrator credentials exposed the template editor. The resulting server-side execution ran as www-data and yielded the first flag.


Joomla's configuration disclosed database credentials. An application table contained several recoverable user passwords.
