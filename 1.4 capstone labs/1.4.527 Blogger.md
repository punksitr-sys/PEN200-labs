#### Recap
Directory discovery identified a WordPress site. Its vulnerable wpDiscuz plugin yielded initial server-side code execution.

The lab exposed three local privilege escalation paths.
Path one: vulnerable SUID pkexec yielded root access through PwnKit.
Path two: a weak Vagrant credential exposed unrestricted passwordless sudo.
Path three: an obfuscated credential exposed the James account. A root cron job trusted James's writable directory in its executable search path.
