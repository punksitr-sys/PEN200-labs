#### Recap
A web directory exposed a password list, and weak SSH credentials gave initial access to a restricted shell. Further enumeration revealed another account and a sudo rule that trusted an executable under a different user's home directory.

A backup private key exposed by the web server granted access to the account that controlled the executable path. The unsafe sudo rule then led to elevated privileges.
