#### Recap
SSH and HTTP were exposed. The first wordlist missed the election directory, while a broader recursive scan found it and a log file containing credentials.
```txt
[2020-01-01 00:00:00] Assigned Password for the user love: P@$$w0rd@123
[2020-04-03 00:13:53] Love added candidate 'Love'.
[2020-04-08 19:26:34] Love has been logged in from Unknown IP on Firefox (Linux).
```
The exposed credential authenticated over SSH and yielded the first flag.

Local enumeration identified vulnerable SUID pkexec. PwnKit led to root access and the second flag.
