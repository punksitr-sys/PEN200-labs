#### Recap
The web application on port 8080 exposed local and remote file inclusion. Local inclusion could reach Apache logs containing untrusted request data, and remote inclusion provided a separate route to initial execution.

The backup directory contained a writable executable that a note described as running every five minutes. The executing identity was initially unknown.
```powershell
icacls C:\Backup

icacls C:\Backup\TFTP.EXE

# Review running processes
wmic process get Name,ProcessId,CreationDate
```
The scheduled execution test confirmed that Administrator launched the writable program, yielding administrator access.
