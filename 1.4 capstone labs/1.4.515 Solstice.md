#### Recap
The book parameter on the service at port 8593 was vulnerable to local file inclusion.
The application could include Apache's access log. Because that log held untrusted request data, the combination led to execution as the web service account.

Two independent paths yielded root access: vulnerable SUID pkexec and a root-run PHP service that trusted a page writable by www-data. The PHP service listened only locally.
