#### Recap
The login returned an account-not-found message for an incorrect password, so the error text alone could not reliably identify a valid account. I compared the HTTP responses in Burp.

The site identified Koken CMS. A referenced JavaScript asset exposed the specific version, which helped match the upload issue.

Unsafe upload handling yielded initial access, and vulnerable SUID pkexec yielded root access.
