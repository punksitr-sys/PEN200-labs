#### Recap
The scan found SSH and HTTP. An HTML comment exposed a username, and robots.txt contained a Base64-encoded value.
The decoded value did not resolve to a hidden path. It worked as the account password over SSH and exposed the first flag.

The kernel release alone did not identify a useful finding. LinPEAS highlighted OverlayFS, and checking the target kernel and architecture clarified which published issue was relevant. The subsequent test confirmed root access.

The SUID pkexec binary was a separate lead, but the PwnKit binary did not run. I did not determine the cause.
