#### docker
Selena could control a rootful Docker daemon. A locally available Alpine image made it possible to confirm that the daemon exposed the host filesystem to privileged container processes.
```bash
docker run -v /:/mnt --rm -it alpine chroot /mnt /bin/sh
```

The FTP account could read an SSH private key. A note identified Ariana as the associated user, and SSH access yielded the first flag.

The messenger script trusted user input as executable code, and a sudo rule ran it as Selena. Selena's Docker access then crossed the container boundary and yielded root access.
