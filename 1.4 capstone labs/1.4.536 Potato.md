#### Recap
Anonymous FTP exposed the login source. A loose comparison of the strcmp() result allowed authentication to be bypassed. An authenticated file inclusion flaw exposed the web administrator's password hash, and the recovered password provided SSH access.

The lab supported two independent elevation paths. Vulnerable SUID pkexec yielded root access, and the sudo rule for nice exposed privileged execution through its permitted command arguments.
```bash
sudo /bin/nice /notes/../bin/bash
```

Key concept one: validate credentials as strings and avoid loosely comparing error results with numeric zero.
Key concept two: sudo rules for command launchers must constrain the executable and its arguments.
