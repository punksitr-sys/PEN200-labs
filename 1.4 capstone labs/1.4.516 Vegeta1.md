#### Recap
Discovering the Bulma directory was the key enumeration step. The wordlists I initially tested did not include it.
The Morse code recording disclosed an SSH username and password.
```txt
USER : TRUNKS PASSWORD : US3R(S IN DOLLARS SYMBOL)
```
The exposed credential authenticated as Trunks and yielded the first flag.

The shell history showed account maintenance commands. File ownership confirmed that Trunks could modify the local account database.
```bash
ls -lsa /etc/passwd
# 4 -rw-r--r-- 1 trunks root 1486 Jun 28  2020 /etc/passwd
```
The writable account database allowed a privileged account entry, exposing the root flag.
