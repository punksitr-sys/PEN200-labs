#### Recap
The HTTP service exposed a password-protected archive containing copies of passwd and shadow. An exposed sha512crypt password was recoverable and provided SSH access. The account started in restricted Bash, but an available editor broke that restriction.

Two local privilege escalation paths
Path one: the SUID pkexec binary was vulnerable to PwnKit and yielded root access.
Path two: process monitoring showed root periodically running Chkrootkit 0.49. The vulnerable version trusted a file in a writable temporary directory, which yielded root access on a subsequent run.

Why did the Chkrootkit check cross the privilege boundary?
CVE-2014-0476 affects Chkrootkit before version 0.50. The root-run check could execute an untrusted file from a writable temporary directory without validating its ownership.
