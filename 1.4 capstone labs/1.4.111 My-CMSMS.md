#### Recap
Identify the application's salted MD5 format. The application combined its site identifier with the password before hashing.

Review the administrator directory for HTTP authentication configuration, including .htpasswd.

Distinguish Base64 from Base32 before decoding candidate values.

Key concept 1: Passwordless sudo access to a general-purpose interpreter can grant privileged code execution.
```bash
python -c 'import os;os.system("/bin/bash")'
```

Key concept 2: Recognize and decode Base64 and Base32 correctly.
```bash
echo 'TUZaRzIzM1ZPSTVGRzJESk1WV0dJUUJSR0laUT09PT0=' | base64 -d
# MFZG233VOI5FG2DJMVWGIQBRGIZQ====
echo 'MFZG233VOI5FG2DJMVWGIQBRGIZQ====' | base32 -d
# armour:Shield@123
```

Key concept 3: Linux ignores the SUID bit on scripts.
