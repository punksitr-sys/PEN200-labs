#### Recap
The HTTP service on port 80 ran WordPress. Weak credentials and an unsafe media upload feature led to an application user shell.

LinPEAS flagged several kernel vulnerabilities. Dirty COW did not yield elevated access, but an eBPF vulnerability (CVE-2017-16995) led to root access on the Ubuntu 16.04 lab host.
