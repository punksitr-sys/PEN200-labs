#### Recap
Anonymous FTP revealed likely account names without exposing file contents. A weak FTP administrator password opened the web root and disclosed an APR1 hash. The recovered web credential authenticated on port 242, and the writable FTP-backed document root led to code execution.
The service token held SeImpersonatePrivilege. A compatible impersonation assessment for the 32-bit Windows Server 2008 environment confirmed administrator access.
