#### Recap
An anonymous SMB share exposed SQL Server credentials in a procedures document. The database session yielded no useful records, but outbound SQL Server authentication exposed a service account. A SQL Server backup log then disclosed another user's password, which led to the user flag.
An ESC1 certificate template permitted requester-supplied identity information. Certificate-based authentication exposed privileged directory operations, and local administrator access produced the root flag.


Key Concepts:
1. SQL Server extended procedures can trigger outbound SMB authentication. Restrict unnecessary outbound access.
2. Review application-specific directories and archived logs for inadvertent credential disclosure.
3. An internal CA certificate is a lead for reviewing AD CS. Confirm ESC1 exposure from the template settings and enrollment permissions.
