#### Recap
The Jenkins Script Console provided code execution and access to the user flag. Impersonation-based elevation attempts failed, but a weakly protected KeePass database exposed credential material accepted for the Administrator account. The root flag was stored in an NTFS alternate data stream rather than as a standalone desktop file.

Key Concepts:
1. KeePassXC can open and inspect a KeePass vault when the password is known.
2. NTFS alternate data streams can hold data that ordinary directory listings do not show.
