#### Recap
LDAP exposed credentials that led to an SMB share containing a recoverable VNC password. The Audit Share group then provided access to binaries and an audit database. Analysis showed that the application could recover the stored ArkSvc password. That account could read deleted directory objects, one of which exposed a password reused by the administrator.


Key Concepts:
1.  Reversible storage of VNC passwords puts credentials at risk.
2. SQLite databases can contain sensitive application records.
3. A .NET decompiler can reveal how an application handles stored credentials.
