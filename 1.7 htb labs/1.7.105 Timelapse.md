#### Recap
An SMB share exposed a password-protected PKCS#12 bundle. Its weak password put the private key at risk and led to certificate-based WinRM access and the user flag.
```bash
evil-winrm -i 10.129.42.115 -u legacyy -P 5986 -S -c cert.crt -k priv.key
```

WinPEAS identified exposed svc_deploy credentials. That account belonged to LAPS_Readers and could read the legacy LAPS password for DC01, which led to administrator access and the root flag.

Key Concepts:
1. PKCS#12 bundles can contain both a certificate and its corresponding private key. Protect the bundle and its password.
2. Review the effective permissions of LAPS_Readers on computer objects and restrict access to the legacy password attribute.
