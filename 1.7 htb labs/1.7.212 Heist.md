Cisco Type 7
Cisco Type 7 uses reversible XOR-based obfuscation with a fixed key. Treat a Type 7 value as recoverable plaintext.
```python
#!/usr/bin/env python3

import sys
from binascii import unhexlify

if len(sys.argv) != 2:
    print(f"Usage: {sys.argv[0]} [level 7 hash]")
    exit()

static_key = "tfd;kfoA,.iyewrkldJKD"
enc = sys.argv[1]
start = int(enc[:2], 16) - 1
enc = unhexlify(enc[2:])
key = static_key[start:] + static_key[:start]

plain = ''.join([chr(x ^ ord(key[i % len(key)]))  for i, x in enumerate(enc)])
print(plain)
```

#### Recap
A public attachment exposed one md5crypt hash and two Cisco Type 7 passwords. The forum and RPC account lookups revealed usernames. Reused passwords led to WinRM access as Chase and the user flag.

Firefox was running on the host. Its process memory contained the administrator password in plaintext.
```bash
grep -aoE 'login_username=.{1,20}@.{1,20}&login_password=.{1,50}&login=' firefox.exe_260816_070542.dmp
```
WinRM access as Administrator yielded the root flag.


Key Concepts:
1. Recognize Cisco Type 7 values in network device configurations and replace them with stronger credential storage.
2. Process memory dumps can contain plaintext credentials. Their presence depends on what the process was doing and when the dump was taken.
