#### Recap
The HR share exposed a plaintext password, guest SMB access exposed account names, and one domain account reused the password. Further review found plaintext credentials in an AD user description and in a script on the DEV share. The account exposed by the script could authenticate over WinRM and read the user flag.

The account belonged to Backup Operators and held SeBackupPrivilege, which exposed protected registry data to backup operations.
```bash
reg save hklm\sam C:\Users\emily.oscars.CICADA\Documents\sam.hive

reg save hklm\system C:\Users\emily.oscars.CICADA\Documents\system.hive
```
The exposed registry data contained local administrator credential material, which led to administrator access and the root flag.


Key Concepts:
1. Guest SMB access can expose domain account information over TCP port 445.
2. Authenticated LDAP queries can expose readable directory attributes over TCP port 389.
