#### Recap
Gibbon CVE-2023-45878 yielded initial code execution. Application configuration exposed database credentials, and the database contained a salted password hash for an application user. The recovered credentials led to Kerberos SSH access and the user flag after the clock and hostname issues were resolved.

A deleted archive exposed another user's password. BloodHound showed that the account could create GPOs and change links on the domain root. Those combined rights allowed domain policy to run code as SYSTEM, yielding the root flag.

Key Concepts:
1. Gibbon is a school management platform. CVE-2023-45878 can lead to remote code execution.
2.  Identify the application's salted SHA-256 password format before evaluating its storage strength.
3. Compare client and KDC timestamps in UTC when troubleshooting Kerberos clock skew.
4.  A Kerberos client uses a ticket-granting ticket to obtain service tickets.
5. SSH GSSAPI can authenticate using cached Kerberos credentials.
6. Audit WriteGPLink and GPO creation rights together when assessing domain-wide policy control.
