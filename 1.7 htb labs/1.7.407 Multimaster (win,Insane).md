#### Recap
The web application exposed SQL injection. Input encoding affected validation, and the database disclosed several distinct password hashes. The initial account list was incomplete, so I reviewed domain identity information to find the affected accounts.

An exposed editor debugging interface gave access as Cyork. A custom assembly contained an embedded password that worked for another account. Subsequent directory and local privilege assessment identified several paths, including Netlogon CVE-2020-1472.

Key Concepts:
1. Apply consistent input normalization and use parameterized SQL queries.
2. Assess whether account lookup interfaces expose domain identities by RID.
3. Restrict debugger access to trusted local processes.
4.  Verify remediation for Netlogon CVE-2020-1472.
