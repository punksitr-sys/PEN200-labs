#### Recap
The printer configuration exposed the service account credentials, leading to WinRM access and the user flag. Registry backup access and the driver-loading privilege did not yield elevated access. Server Operators membership allowed control of services running as SYSTEM, which ultimately led to SYSTEM access.

Key Concepts:
1. Registry backups can expose local account credential material.
2.  Server Operators membership can grant service management rights on a domain controller. Services configured to run as SYSTEM make this a sensitive privilege.

Consult a write-up after an hour without progress on privilege escalation to identify knowledge gaps.
