#### Recap
The initial SQL session exposed outbound authentication from the SQL Server service. The resulting service credential made forged service tickets possible. SQL Server accepted a privileged identity, which enabled command execution as the service account and yielded the user flag.

Additional domain authentication services became reachable during the privilege escalation assessment.
The OPENROWSET BULK approach was not reproduced because the SQL execution context could not read the target file.
The NTLM relay path involving CVE-2025-33073 provided enough access to read the root flag after a reset. It did not provide a fully interactive shell.
The final path exposed a token with SeImpersonatePrivilege through local SMB authentication and led to SYSTEM access.

Key Concepts:
1. OPENROWSET BULK can expose local files when the SQL execution context can read them.
2. Audit AD DNS write permissions and limit unnecessary outbound domain-controller authentication.
3. CVE-2025-33073 can undermine SMB reflection protections. Verify that affected Windows hosts are patched.
4. Assess effective impersonation privileges and the tokens exposed by service authentication paths.
