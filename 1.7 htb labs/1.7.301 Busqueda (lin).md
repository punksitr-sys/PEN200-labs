#### Recap
The Searchor command injection vulnerability led to initial access. Repository data exposed a reused service-account password. A privileged diagnostic script exposed container metadata, and database credential reuse opened the administrative Gitea interface. The script's unsafe path handling led to root access.

Key Concepts
1. Assess Searchor deployments for CVE-2023-43364.
2. Container inspection can expose configuration and sensitive metadata.
