#### Recap

The profiles share exposed likely account names. The support account lacked Kerberos preauthentication and was exposed to offline password guessing. BloodHound then identified a delegated password-reset right over audit2020, which led to access as that account.
```bash
rpcclient -U support //IP

# SMB RPC account administration
setuserinfo2 audit2020 23 Pass123
```
Access to the forensic share exposed a Windows memory dump containing svc_backup credential material. That account could authenticate over WinRM and read the user flag.
```bash
pypykatz lsa minidump lsass.DMP
```

The backup account held privileges that allowed it to access protected directory data through the Windows Backup API. Exposure of the Active Directory database ultimately led to domain administrator access and the root flag.

Key Concepts:
1. ForceChangePassword allows a delegated principal to reset another account's password.
2. Treat LSASS memory dumps as sensitive credential-bearing artifacts.
3. Review Backup Operators membership and SeBackupPrivilege on domain controllers, including access to protected files in shadow copies.
