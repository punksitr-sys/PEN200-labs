doas lets authorized users run commands under another account, commonly root.

#### Recap
TinyFileManager accepted default credentials and allowed server-side code execution. A second site exposed a Boolean SQL injection through its WebSocket ticket check. The database disclosed the player account's credentials, which led to the user flag.
A doas rule ran dstat as root while its plugin search path included a writable directory. This allowed an unprivileged account to affect privileged execution, leading to the root flag.

Key Concepts:
1. Review doas rules together with the plugin and configuration paths trusted by permitted programs.
