#### Recap
SQL injection in the search field exposed site accounts and password hashes. After authenticating, I found unsafe PHP file handling that led to server-side code execution. Application configuration exposed database credentials, and a recovered domain password led to WinRM access and the user flag.

The Firefox profile exposed additional credentials. Group ownership and delegated membership rights opened access to CORE STAFF, which could read the domain controller's legacy LAPS password. Administrator access yielded the root flag.

Key Concepts:
1. SQL injection can expose password hashes and, in some configurations, trigger outbound authentication.
2. Review local file inclusion and PHP stream-wrapper handling together.
3. Protect Firefox profile data because it may contain recoverable saved credentials.
4. Review group ownership alongside the rights to change its ACL and membership.
