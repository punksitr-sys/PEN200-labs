#### Recap

The notes application trusted a client-controlled JWT key reference and accepted an administrator claim under an untrusted signature. The resulting administrative access exposed server-side execution through the upload feature.

Passwordless Docker access exposed a vulnerable runc runtime (CVE-2019-5736). The container escape reached the host, resulting in root access and the root flag.

Key Concepts:
1. Restrict JWT verification to trusted keys and do not resolve arbitrary key references from token headers.
2. Restrict administrative uploads that could lead to code execution.
3. Review permission to invoke Docker through sudo.
4. Patch runc and assess whether container access can expose the host.
5. Review local backups for private keys and restrict access to them.
