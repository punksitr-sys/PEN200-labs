#### Recap
An anonymously accessible SMB share exposed a Group Policy Preferences file containing recoverable service account credentials. A CIFS service principal registered to a domain administrator then exposed that administrator account to offline password guessing.

> Group Policy Preferences could store credentials with a publicly known encryption key, allowing anyone who could read the policy file to recover the password.
> This vulnerability, addressed in Microsoft security bulletin MS14-025, primarily affects Windows Server 2008 through Windows Server 2012 R2 domain environments. Remediation: Install update KB2962486.
