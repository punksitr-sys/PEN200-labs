#### Recap
Request Baskets SSRF exposed an internal Maltrail 0.53 instance. Its unauthenticated command injection yielded a shell as puma and the user flag.
A passwordless sudo rule allowed the service status command to invoke a privileged pager. That led to root access and the root flag.

Key Concepts:
1. Request Baskets CVE-2023-27163 exposes internal HTTP services through SSRF.
2. Maltrail 0.53 was vulnerable to unauthenticated command injection.
3. Review sudo rules for programs that launch interactive pagers.
