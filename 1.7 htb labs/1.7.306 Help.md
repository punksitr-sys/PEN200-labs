#### Recap
The HelpDeskZ ticket endpoint saved attachments before validating them and left rejected files in a web-accessible directory. The predictable naming and PHP execution context led to initial shell access. A separate GraphQL exposure supplied credentials for an authenticated SQL injection assessment.
A local kernel vulnerability led to root access. The kernel release string alone did not establish the effective patch level.

Key Concepts:
1. GraphQL clients can request several fields in one query.
2. Assess Linux kernel vulnerabilities against the distribution's package and patch history.
