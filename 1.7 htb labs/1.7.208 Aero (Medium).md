#### Recap
The web application's file upload path exposed Windows theme handling to ThemeBleed (CVE-2023-38146), which yielded initial access and the user flag. A document on the host pointed to a CLFS kernel vulnerability (CVE-2023-28252). That issue led to SYSTEM access and the root flag.

Key Concepts:
1. ThemeBleed (CVE-2023-38146) is a race condition in Windows theme handling.
2. CVE-2023-28252 is a local privilege escalation vulnerability in the Windows Common Log File System driver.
