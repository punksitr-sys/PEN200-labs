#### Recap
The exposed Git repository revealed an internal upload application and its access checks. File validation failed to account for PHP archive handling. The remaining PHP process functionality enabled an application shell. A SUID helper running Python 2 then exposed the developer identity.

A passwordless sudo rule allowed the developer account to run a package installer as root.
```bash
echo "import os; os.execl('/bin/bash', 'bash', '-p')" > setup.py
sudo easy_install /tmp/air
```
The sudo rule led to root access and the root flag.

Key Concepts
1. Use browser developer tools or an extension to inspect custom request header behavior.
2. Review exposed PHP configuration and disabled functions.
3. Restrict PHP process execution functions where the application does not need them.
4. Replace Python 2 input() with non-evaluating input handling.
5. Do not delegate package installers through unrestricted sudo rules.
