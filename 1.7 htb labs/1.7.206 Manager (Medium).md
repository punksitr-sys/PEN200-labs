#### Recap
Weak SQL Server credentials provided initial access. Directory enumeration revealed a website backup, and an old configuration file inside it exposed the raven account's credentials. WinRM access as that account yielded the user flag.

The CA review identified ESC7. Excessive CA management rights exposed certificate approval and issuance controls, ultimately allowing authentication as the domain administrator and access to the root flag.

Key Concepts:
1. Check whether users select their account names, including lowercase variants, as passwords.
2.  Audit Manage CA and Manage Certificates rights when assessing ESC7. These rights are assigned at the CA level.
