#### Recap
 An anonymously accessible backup exposed database credentials. One password opened an archive holding an Outlook mail store. An email disclosed the security account's password, which provided Telnet access and the user flag.

The security account's profile contained DPAPI-protected credentials and associated master key files. The first analysis environment did not support the required tooling. Offline analysis in a Windows VM showed that the saved administrator credential was recoverable, leading to the root flag.

Key Concepts:
1. Use format-appropriate tools to inspect Access databases, Outlook PST files, and mbox archives.
2. The ARM-based Windows VM ran the credential analysis tool successfully in this lab.
