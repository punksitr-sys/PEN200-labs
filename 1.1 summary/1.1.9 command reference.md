## Enumeration

### Nmap

> **Interpretation:** Compare scan scope and probe type before reading a missing result as evidence. A port outside the scan set has not been checked. A filtered result means the scan could not determine whether the port was open.

- [ ] TCP
- [ ] UDP

Add the host record `192.168.135.157  IP` to `/etc/hosts`.

tcp
```bash
sudo nmap -Pn -sS --open -p- -O IP --min-rate 2000 -oN ports

sudo nmap -Pn -sC -sV IP -p $(getports ports) -oN nmap
```
[getports](https://github.com/punksitr-sys/scripts/blob/main/get_ports.py)

udp
```bash
sudo nmap -Pn -n IP -sU --top-ports=100 --reason -oN udp_ports
```
