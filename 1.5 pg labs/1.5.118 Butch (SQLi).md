Remote UAC can filter administrator tokens for local accounts during network logon. The built-in Administrator account may be treated differently depending on policy.

Remote management access allowed authentication but did not grant an unfiltered administrator token.

Changing LocalAccountTokenFilterPolicy can relax remote UAC token filtering for local administrator accounts. That change expands remote administrative access and should be treated as security-sensitive.
```powershell
# Remote administrator token filtering policy
New-ItemProperty -Path "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System" -Name "LocalAccountTokenFilterPolicy" -Value 1 -PropertyType DWord -Force

# Restore the original registry state
Remove-ItemProperty -Path "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System" -Name "LocalAccountTokenFilterPolicy" -Force

# Verify that the original policy state was restored
Get-ItemProperty -Path "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System" -Name "LocalAccountTokenFilterPolicy" -ErrorAction SilentlyContinue
```

#### Recap
The login endpoint on port 450 allowed SQL injection to modify a user's stored credential. The authenticated upload feature accepted an ASP.NET handler that ran as SYSTEM. The privileged context led to administrator access through WinRM.

Key Concepts
1. Use a bounded set of tests to reason about schema information when a blind injection does not return query results.
2. Verify the effective execution identity. A stable command interface can be sufficient to demonstrate impact.
