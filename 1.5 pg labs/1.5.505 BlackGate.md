#### Recap
The exposed Redis deployment allowed remote code execution, yielding an initial shell.

Local privilege escalation
Path one: the SUID pkexec binary was vulnerable to PwnKit, which yielded root access.
Path two: the redis-status binary exposed its authentication key. A sudo rule ran the tool as root, and its interactive interface allowed privileged execution.
