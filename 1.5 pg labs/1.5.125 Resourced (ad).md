#### Recap
SMB enumeration disclosed an initial credential. The account could read a backup containing the AD database and SYSTEM hive. The backup exposed multiple credential records, and one valid record provided WinRM access and the user flag.

BloodHound showed that the accessible account held GenericAll over the domain controller's computer object. That delegation exposed its RBCD configuration and led to privileged remote access.

Key Concepts:
1. Audit write access to computer objects and their resource-based constrained delegation settings.
2. Protect directory database and registry backups as credential-bearing data.
