#### Recap
A GlassFish file inclusion flaw exposed SynaMan credentials. RDP access yielded the user flag. The local GlassFish console allowed application deployment without authentication, and the deployed application ran as SYSTEM.

Key Concepts
1. Application configuration files can expose credentials through file inclusion flaws.
2. Require authentication for administrative consoles even on loopback, especially when they can deploy server-side applications.
