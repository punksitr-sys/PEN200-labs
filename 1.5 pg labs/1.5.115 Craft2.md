#### Recap
The document processing path bypassed the original macro restriction and exposed outbound NTLM authentication. The recovered Apache password did not work for direct remote logon, but it opened a writable SMB location mapped to the web root, leading to an application shell.

The loopback-only phpMyAdmin interface exposed a privileged MySQL service. Its file write capability put a trusted DLL location at risk. The resulting NETWORK SERVICE session held an impersonation privilege that led to SYSTEM access.
