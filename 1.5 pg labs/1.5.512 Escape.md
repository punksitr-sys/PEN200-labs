#### Recap

The initial shell ran inside Docker. Mount information and the SNMP configuration showed that a host-side command extension relied on a path writable from the container. This trust boundary failure led to host execution.

After reaching the host, PwnKit (CVE-2021-4034) provided one root path. A separate SUID helper trusted an inherited search path, and subsequent OpenSSL testing exposed restricted files. The notes did not conclusively establish the OpenSSL process's privilege mechanism.

Key Concepts:
1. Review container mounts for paths shared with privileged host services.
2. Restrict access to SNMP and audit external command extensions.
3. Prevent host services from executing content from paths writable inside containers.
4. Patch pkexec for PwnKit (CVE-2021-4034).
5. Use absolute executable paths and a controlled environment in SUID programs.
6. Distinguish file capabilities from the effective privileges of a running process.
7. Verify what files an elevated server can expose and restrict its serving scope.
