>With the policy enabled at both scopes, an MSI package can run installation actions with SYSTEM privileges.

#### Recap
An SMB share exposed the WordPress administrator's password. Access to the WordPress theme editor led to initial code execution. Local checks then showed that AlwaysInstallElevated was enabled in both policy scopes, allowing elevation to SYSTEM.
