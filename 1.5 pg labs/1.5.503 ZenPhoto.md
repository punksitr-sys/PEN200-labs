#### Recap
The deployed Zenphoto CMS had a known remote code execution vulnerability, which led to an initial shell.

Local privilege escalation
Path one: PwnKit in the SUID pkexec binary led to root access.
Path two: the Linux Reliable Datagram Sockets vulnerability (CVE-2010-3904) led to kernel-level privilege escalation.
