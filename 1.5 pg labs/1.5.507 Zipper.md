#### Recap
File disclosure exposed the upload and inclusion logic. The application accepted an archive and could evaluate content inside it through PHP's stream handling, yielding execution as www-data.

Local privilege escalation
Path one: the SUID pkexec binary was vulnerable to PwnKit and yielded root access.
Path two: the scheduled backup script exposed the root password in its logs. The credential provided root access.
