The process list showed that GlusterFS was running.
The GlusterFS snapshot scheduler's symbolic link handling (CVE-2018-1088) exposed a potential container escape.

When the snapshot scheduler was enabled, a host cron configuration link pointed into GlusterFS shared storage. This linked host-scheduled execution to the integrity of the shared volume.

Container boundary assessment
1. The container could reach the shared GlusterFS volume.
2. The shared storage was writable from outside the host's administrative trust boundary.
3. The host scheduler processed data from that volume as root, enabling execution on the host.
